# VisitorLog

A simple console-based Java application to record visitors and their visit dates.

## Features
- Add a visitor with name, purpose, and visit date
- View all visitor records
- Search visitors by name
- Remove a visitor record by ID
- Validate date and menu input

## Concepts Used
- Classes and objects
- Encapsulation
- ArrayList and List
- Loops and switch statements
- Methods
- Scanner for user input
- Exception handling
- LocalDate for visit dates

## Requirements
- Java 8 or later

## Run the Application

Open a terminal in the `VisitorLog` folder and run:

```bash
javac -d out src/*.java
java -cp out Main
```

## Note
This beginner version stores visitor records in memory. Records are cleared when the application exits.
